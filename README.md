# Plataforma Móvil para una Academia

## 📚 Descripción

Este proyecto consiste en el desarrollo de una **plataforma móvil para la gestión de una academia**, diseñada con el objetivo de facilitar el acceso y la administración de información relacionada con estudiantes, cursos y otros servicios académicos.

La solución está compuesta por una aplicación móvil y un sistema backend que permite gestionar y proporcionar la información necesaria para el funcionamiento de la plataforma.

El proyecto busca aplicar conocimientos relacionados con el desarrollo de aplicaciones móviles, la comunicación entre aplicaciones cliente y servidores, la gestión de bases de datos y el desarrollo de APIs.

## 🛠️ Tecnologías utilizadas

Entre las principales tecnologías empleadas en el desarrollo del proyecto se encuentran:

* **Laravel** para el desarrollo del backend.
* **PHP** como lenguaje de programación del servidor.
* **Android** para el desarrollo de la aplicación móvil.
* **Base de datos** para el almacenamiento y gestión de la información.
* **API** para la comunicación entre la aplicación móvil y el backend.

## 📁 Estructura general del proyecto

El repositorio se encuentra organizado en diferentes directorios, entre los cuales destacan:

* `app/`: Contiene la lógica principal del backend.
* `config/`: Archivos de configuración del proyecto.
* `database/`: Migraciones y archivos relacionados con la base de datos.
* `routes/`: Definición de las rutas y endpoints de la aplicación.
* `resources/`: Recursos utilizados por el proyecto.
* `mobile/academia-update-app/`: Contiene el código fuente de la aplicación móvil.

## 🎯 Objetivo

Desarrollar una solución tecnológica que permita mejorar la gestión y el acceso a los servicios de una academia mediante una plataforma móvil conectada a un sistema backend.
